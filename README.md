# Rillvane Protocol

Solana inventory-pool program and Node.js API for the RLVN / USDC development market. This repository includes fixed-point accounting, single-asset supply shares, collateral-backed credit, wallet-bound authorization and a WebSocket market stream.

## Status

Development software; not independently audited. Mainnet execution is disabled. Bootstrap creates placeholder configuration, not a deployed chain market. The local projection engine and its tests do not establish that an operation settled on-chain. Real chain use needs matching deployed accounts, RPC and separately provisioned authority keys.

## Quick start

Requires Node.js 24. The API has no npm runtime dependencies.

~~~sh
cp .env.example .env
npm run bootstrap
npm start
~~~

PowerShell: use Copy-Item .env.example .env instead of cp if preferred. The API is at http://localhost:8787/api/health; / returns 404 in API-only mode. The default validator RPC may be unavailable until you configure it. No private keys are included or generated by bootstrap.

~~~sh
npm run check
npm test
npm run verify:flow
cargo test --locked --manifest-path programs/rillvane/Cargo.toml
~~~

## Repository map

| Directory | Purpose |
| --- | --- |
| programs/rillvane | Rust Solana program and native tests |
| backend | API, auth, engine, database, RPC, workers and tests |
| scripts | Explicit bootstrap, test-flow and devnet operator commands |
| docs | Architecture, economics and deployment |
| ops | Example service and proxy configuration; no live keys or registry |

The frontend is a separate sibling checkout, [rillvane-app](https://github.com/Rillvane/rillvane-app). Those GitHub destinations are intended repository names and may not exist until you publish them. Set FRONTEND_ROOT=../rillvane-app/dist and SITE_MODE=app to serve it at / on the same API origin.
